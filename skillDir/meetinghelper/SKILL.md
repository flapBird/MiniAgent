## Description
处理所有与会议相关的任务，包括：会议记录整理、会议摘要生成、待办事项提取、会议议程创建、会议邀请起草、会议纪要格式化、参会人员信息整理、会议时间安排建议、会议跟进邮件撰写等。

## Triggers
使用此技能的触发条件：
- 用户提到"会议"、"meeting"、"会议记录"、"会议纪要"
- 需要整理会议内容、提取行动项
- 创建会议议程、会议邀请
- 总结会议要点、决策事项
- 准备会议材料或后续跟进
- 处理会议录音转录文本
- 分析会议效率或参与度

## Core Capabilities

### 1. 会议记录处理
- 将非结构化的会议记录转换为清晰的格式
- 识别并突出关键讨论点
- 提取决策、行动项和责任人
- 生成时间线或讨论流程

### 2. 会议摘要生成
- 创建简洁的会议摘要（执行摘要）
- 按主题或议题分类内容
- 识别未解决的问题和后续步骤
- 生成多种长度版本（简短/详细）

### 3. 行动项管理
- 提取所有待办事项
- 识别责任人和截止日期
- 按优先级排序
- 生成可追踪的任务列表

### 4. 会议准备
- 创建结构化议程
- 准备讨论要点
- 生成会议邀请文本
- 建议时间分配

### 5. 会议跟进
- 起草跟进邮件
- 创建决策记录
- 生成分享版本的会议纪要
- 准备下次会议的衔接材料

## Output Formats

根据用户需求选择合适的输出格式：

1. **结构化 Markdown**：日常会议记录和摘要
2. **Word 文档 (.docx)**：正式会议纪要、需要分享的文档
3. **表格形式**：行动项追踪、参会人员信息
4. **邮件格式**：会议邀请、跟进邮件

## Processing Guidelines

### 信息提取优先级
1. **关键决策**：会议中做出的重要决定
2. **行动项**：Who（谁）、What（做什么）、When（截止时间）
3. **讨论要点**：主要话题和观点
4. **未解决问题**：需要后续跟进的事项
5. **数据和事实**：提到的具体数字、日期、名称

### 格式化标准
- 使用清晰的标题层级
- 用粗体标记责任人和截止日期
- 用列表组织多个条目
- 保持时间顺序（如适用）
- 区分事实陈述和观点

### 语言风格
- 简洁明了，避免冗余
- 使用主动语态
- 保持客观中立
- 适当使用专业术语
- 中英文混合时保持一致性

## Example Use Cases

**案例 1：整理会议录音转录**
输入：一段杂乱的会议转录文本
输出：结构化的会议纪要，包含摘要、讨论要点、决策、行动项

**案例 2：提取行动项**
输入：长篇会议记录
输出：清晰的待办事项列表，标注责任人和截止日期

**案例 3：准备会议议程**
输入：会议主题和目标
输出：时间分配合理的议程，含讨论要点

**案例 4：生成会议邀请**
输入：会议基本信息
输出：专业的会议邀请邮件

**案例 5：会议后跟进**
输入：会议纪要
输出：跟进邮件，提醒行动项和下次会议安排

## Quality Checklist

输出前确认：
- [ ] 所有行动项都有明确的责任人
- [ ] 重要决策都被突出标记
- [ ] 信息组织逻辑清晰
- [ ] 没有遗漏关键信息
- [ ] 格式统一且易读
- [ ] 时间信息准确（日期、时长）
- [ ] 适合目标受众（内部/外部）

## Integration Points

此技能可能需要配合：
- **docx skill**：生成正式的 Word 格式会议纪要
- **Gmail/Outlook 连接器**：直接发送会议邀请或跟进邮件
- **日历连接器**：安排会议时间
- **项目管理工具**：导出行动项到任务系统

## Common Pitfalls to Avoid

1. **不要**直接复制粘贴大段原文，而应提炼要点
2. **不要**遗漏没有明确说明但隐含的行动项
3. **不要**使用模糊的表述（"尽快"、"稍后"）代替具体时间
4. **不要**忽略非语言信息（如果提供了上下文）
5. **不要**假设背景信息，应基于提供的内容

## Performance Optimization

- 对于长会议记录，先创建大纲再填充细节
- 使用模板加快常规会议的处理
- 为重复性会议保持格式一致性
- 根据会议类型调整输出详细程度
